# 靖翼之憩

> 挫其锐解其纷，和其光同其尘

记录科研日常的个人博客，基于 [Hexo](https://hexo.io/) + [NexT.Gemini](https://theme-next.js.org/) 构建，托管于 GitHub Pages。

## 关于本站

这里将记录我的科研旅程——从文献笔记到实验心得，从学术思考到技术实践。

## 技术栈

| 类别 | 技术 |
|------|------|
| 静态网站生成器 | Hexo 5.x |
| 主题 | NexT.Gemini |
| 托管 | GitHub Pages |

## 本地开发

```bash
npm install
hexo server      # 启动本地预览
hexo generate    # 生成静态文件
hexo deploy      # 部署到 GitHub Pages
```
